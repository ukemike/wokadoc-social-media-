# Wokadoc social media files

Public media files for Wokadoc's scheduled social posts. Buffer downloads each file from this repository when a post is published.

- `week-3/` (2 to 8 November 2026): one Reel per day (`*-reel.mp4`, 9:16), X and LinkedIn images (`*-x.png`, 16:9) and two wide videos (`*-wide.mp4`, 16:9).

Please don't rename or delete files while their posts are scheduled.
